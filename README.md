Система управления ЦОД
======================

Это веб-приложение для управления дата-центрами (ЦОД), разработанное с
использованием Flask. Приложение позволяет управлять ЦОДами, коммутаторами,
серверами, пользователями и подключениями.

Функционал
----------

-   Авторизация и регистрация пользователей с ролями (Администратор, Инженер
    ЛВС, Наблюдатель).

-   Управление ЦОДами (добавление, редактирование, удаление).

-   Управление коммутаторами и серверами.

-   Загрузка и удаление подключений.

-   Отчеты о подключениях.

-   Логи действий пользователей.

-   Настройки приложения (для администраторов).

-   Локализация (RU/EN).

-   Пагинация, поиск и сортировка в справочниках.

-   Уведомления с анимацией.

-   Обработка ошибок (404, 403, 500).

Установка
---------

1.  Клонируйте репозиторий:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    git clone https://github.com/your-repo/cod-management.git
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

2.  Создаём виртуальное окружение:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    python -m venv venv
    .\venv\Scripts\activate
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

3. Установите зависимости:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    pip install -r requirements.txt
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

4.  Настройте базу данных PostgreSQL.

5.  Запустите приложение:

    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    python main.py
    ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
